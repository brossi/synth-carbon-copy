# Project Guidelines for AI Development

## Time Estimates

**Do not include time estimates in work output** (plans, documentation, commit messages, etc.)

- Estimates lack baselines and historical data
- They set incorrect expectations
- We'll complete work when it's done, with quality as the priority
- Focus on clear deliverables and success criteria instead

## Best Practices

- Break work into clear, testable milestones
- Define success criteria for each deliverable
- Prioritize quality and correctness over speed
- Document what needs to be done, not how long it will take
