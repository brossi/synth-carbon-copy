# Icon Assets

This directory contains icon assets for the Photoshop UXP plugin.

## Required Icons

- `icon-light.png` - Icon for light themes (23x23 pixels, @1x and @2x)
- `icon-dark.png` - Icon for dark themes (23x23 pixels, @1x and @2x)

## Icon Guidelines

- Icons should be 23x23 pixels at 1x scale
- Provide @2x versions (46x46 pixels) for retina displays
- Use PNG format with transparency
- Light icons should work on light/medium backgrounds
- Dark icons should work on dark/darkest backgrounds
